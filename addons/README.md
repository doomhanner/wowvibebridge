# Your addons

Addons you build go here, one folder each. Create one from the template with:

```bash
python tools/wowdev.py new MyAddon --title "My Addon"
```

The kit's own helper addons (DevBridge) live in [devaddons](../devaddons/), so updating the kit
never touches this folder. See [the dev loop](../docs/wiki/guides/dev-loop.md) for every command.
